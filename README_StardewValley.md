# 🌱 RootDown Valley - Stardew Valley Style Drought-Tolerant Farming Game

A 2D pixel art farming simulation game inspired by Stardew Valley, focused on water conservation and sustainable agriculture. Control your character to plant, water, and harvest crops while managing water resources and building a drought-resistant farm.

## 🎮 Game Overview

RootDown Valley combines the charm of Stardew Valley with environmental education about water conservation. Players control a pixel art character who farms various crops, manages water resources, and learns about sustainable agriculture practices.

## 🌟 Key Features

### 🎨 2D Pixel Art Graphics
- **Retro-style pixel art** for all game elements
- **Animated character** with smooth movement
- **Detailed crop sprites** showing growth stages
- **Day/night cycle** with visual changes
- **Weather effects** affecting gameplay

### 🌾 Farming System
- **5 Crop Types**:
  - 🍅 **Tomato** - Standard crop, moderate water needs
  - 🌽 **Corn** - High-value crop, high water needs
  - 🥕 **Carrot** - Quick-growing crop, low water needs
  - 🌼 **Native Flowers** - Drought-tolerant, bonus points
  - 🌱 **Drought Grass** - Extremely drought-resistant

### ⚒️ Tools & Actions
- **Hoe** (1) - Prepare soil for planting
- **Watering Can** (2) - Water crops (uses aquifer water)
- **Seeds** (3) - Plant selected crop type
- **Harvest** (4) - Collect mature crops

### 🌱 Crop Growth Mechanics
- **4 Growth Stages**: Seed → Sprout → Growing → Ready
- **Realistic Growth Time**: Crops grow over multiple days
- **Water Requirements**: Each crop has different water needs
- **Health System**: Crops can die from lack of water
- **Drought Tolerance**: Native plants survive better in dry conditions

### 💧 Water Conservation System
- **Aquifer Management**: Limited water supply that depletes with use
- **Weather Effects**:
  - ☀️ **Sunny** - Normal water loss
  - 🌧️ **Rainy** - Crops get free water
  - 🌵 **Drought** - Double water loss
- **Water Usage Tracking**: Penalties for excessive water use
- **Native Plant Bonuses**: Drought-resistant crops use less water

### 🎯 Scoring System
- **Base Score**: Days survived × 10 points
- **Health Bonus**: +5 points per healthy crop
- **Native Plant Bonus**: +15 points per native crop
- **Water Penalty**: -2 points per water unit used
- **Money System**: Sell crops for profit

### 🌅 Day/Night Cycle
- **Time Progression**: Advance days manually
- **Energy System**: Actions consume energy, restored each day
- **Weather Changes**: Random weather each day
- **Crop Updates**: Crops grow and change each day

## 🎮 Controls

### Movement
- **WASD** or **Arrow Keys** - Move character
- **Space** - Use selected tool
- **N** - Advance to next day

### Tool Selection
- **1** - Select Hoe
- **2** - Select Watering Can
- **3** - Select Seeds
- **4** - Select Harvest Tool

### Seed Selection
- **Q** - Tomato seeds
- **E** - Corn seeds
- **R** - Carrot seeds
- **T** - Native flower seeds
- **Y** - Drought grass seeds

## 🚀 Getting Started

### Installation
1. Install Python 3.7+
2. Install pygame: `pip install pygame`
3. Run the game: `python stardew_valley_game.py`

### Quick Start Guide
1. **Move** your character around the farm
2. **Select a tool** (1-4) and **seeds** (Q-Y)
3. **Prepare soil** with the hoe
4. **Plant seeds** on prepared soil
5. **Water crops** regularly (but conserve water!)
6. **Harvest** when crops are ready
7. **Advance days** to see crops grow
8. **Manage** your water usage and energy
